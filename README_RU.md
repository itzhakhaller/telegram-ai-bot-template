# Шаблон Telegram AI Bot

Универсальный шаблон Telegram-бота на Python с подключением OpenAI API.

Этот проект можно использовать как основу для разных AI-ботов в Telegram, например:

- AI-ассистент
- Переводчик
- Бот поддержки клиентов
- Бот для обработки заявок
- Бот для анализа текста
- Бот для генерации контента
- Простой бот для автоматизации

## Возможности

- Принимает текстовые сообщения из Telegram
- Передаёт сообщение пользователя в OpenAI API
- Возвращает ответ AI обратно в Telegram
- Поддерживает команду `/start`
- Обрабатывает ошибки OpenAI API
- Хранит API-ключи в переменных окружения
- Быстро адаптируется под требования нового клиента

## Технологии

- Python
- Telegram Bot API
- OpenAI API
- python-telegram-bot
- python-dotenv

## Структура проекта

- `bot.py` — основной код бота
- `.env` — API-ключи
- `.gitignore` — запрещает загрузку секретных файлов на GitHub
- `requirements.txt` — необходимые библиотеки Python
- `README.md` — английская инструкция
- `README_RU.md` — русская инструкция

## Настройка

1. Установить необходимые библиотеки:

`pip install -r requirements.txt`

2. Создать файл `.env`.

3. Добавить API-ключи:

`TELEGRAM_TOKEN=your_telegram_token`

`OPENAI_API_KEY=your_openai_api_key`

4. Открыть `bot.py`.

5. Изменить переменную `AI_INSTRUCTIONS` под задачу нового проекта.

Пример:

`AI_INSTRUCTIONS = "Переводи сообщение пользователя на английский язык."`

6. При необходимости изменить сообщение команды `/start`.

7. Запустить бота:

`python bot.py`

## Как адаптировать шаблон под новый заказ

В большинстве похожих заказов достаточно изменить:

1. `AI_INSTRUCTIONS`
2. Сообщение `/start`
3. Проверки и бизнес-логику, если они нужны
4. Дополнительные команды или интеграции по ТЗ клиента

Связка Telegram + Python + OpenAI обычно остаётся без изменений.

## Безопасность

Никогда не загружать реальные API-ключи на GitHub.

Хранить ключи в `.env`.

Проверить, что `.env` находится в `.gitignore`.

## Схема работы

Пользователь Telegram → Python-бот → OpenAI API → ответ AI → пользователь Telegram
